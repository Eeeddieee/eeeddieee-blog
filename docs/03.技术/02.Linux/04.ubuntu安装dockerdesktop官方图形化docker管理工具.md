#  ubuntu安装dockerdesktop官方图形化docker管理工具

## 一、检查及准备安装环境
1.检查是否有安装gnome-terminal

```shell
apt list|grep gnome-terminal
```

出现以下内容说明已经有安装：
```shell
用户及计算机名:/etc/apt$ apt list|grep gnome-terminal

nautilus-extension-gnome-terminal/jammy,now 3.44.0-1ubuntu1 amd64 [已安装，自动]
```
如果没有则执行：

```shell
sudo apt remove docker-desktop
```
2.删除干净旧版docker-desktop

```shell
sudo apt remove docker-desktop
#或者用以下命令彻底删除旧版文件及app
rm -r $HOME/.docker/desktop
sudo rm /usr/local/bin/com.docker.cli
sudo apt purge docker-desktop
```

## 二、安装Docker Desktop

1. 下载deb包

   ```shell
   wget https://desktop.docker.com/linux/main/amd64/docker-desktop-4.26.1-amd64.deb
   ```

   想要获取最新的版本包可以到https://www.docker.com/products/docker-desktop/ 获取

2. 安装**Docker Desktop** 

   ```shell
   sudo apt-get update
   sudo apt-get install ./docker-desktop-<version>-<arch>.deb
   #出现以下提示可以忽略
   N: Download is performed unsandboxed as root, as file '/home/user/Downloads/docker-desktop.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)
   ```

3. 启动/停止Docker Desktop

   ```shell
   systemctl --user start docker-desktop
   systemctl --user stop docker-desktop
   ```

4. 查看是否安装成功

   ```shell
   docker compose version
   Docker Compose version v2.17.3
   
   docker --version
   Docker version 23.0.5, build bc4487a
   
   docker version
   Client: Docker Engine - Community
    Cloud integration: v1.0.31
    Version:           23.0.5
    API version:       1.42
   <...>
   ```

5. 设置开机启动

   ```shell
   # 如果个人电脑使用的话不建议开机启动，因为容器多了会占用资源。用到时启动即可
   systemctl --user enable docker-desktop
   ```
## 三、设置阿里云镜像加速

1. 停止Docker Desktop及其他组件

   ```
   systemctl --user stop docker-desktop
   ```

2. 进入https://cr.console.aliyun.com/cn-shanghai/instances/mirrors ，找到镜像加速器，复制下面的语句运行：

   ```shell
   sudo mkdir -p /etc/docker
   sudo tee /etc/docker/daemon.json <<-'EOF'
   {
     "registry-mirrors": ["https://用户随机字符串.mirror.aliyuncs.com"]
   }
   EOF
   ```

3. 启动Docker Desktop

   ```shell
   systemctl --user start docker-desktop
   ```

4. 进入设置==》Docker Engine粘贴镜像信息，后点击Apply&Restart

   ```json
   {
     "builder": {
       "gc": {
         "defaultKeepStorage": "20GB",
         "enabled": true
       }
     },
     "experimental": false,
     "registry-mirrors": ["https://随机串.mirror.aliyuncs.com"]
   }
   ```
