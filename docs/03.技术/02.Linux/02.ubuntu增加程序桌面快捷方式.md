#  ubuntu增加程序桌面快捷方式


## 1.新建.desktop文件，类似windows的程序快捷方式

新建 xxapp.desktop，如：

```shell 
sudo vim idea.desktop
```

内容填写：

~~~
[Desktop Entry]
Encoding=UTF-8
Name=IntelliJ IDEA
Comment=IntelliJ IDEA
#程序位置
Exec=/opt/idea/bin/idea.sh
#图标位置
Icon=/opt/idea/bin/idea.png
Terminal=true
Type=Application
Categories=GNOME;Application;Development;
StartupNotify=true
~~~

重要配置选择说明：

Name=IntelliJ IDEA：程序要显示的程序名称

Exec=/opt/idea/bin/idea.sh：可执行程序的位置，必须指定

Icon=/opt/idea/bin/idea.png：程序图标位置

Terminal=true：是否同时开一个终端，可以填false，不会开终端。

Type=Application：.desktop文件类型，一般填Application，如果是Link，同时制定URL= http://xxxx 则是超链接，会打开浏览器进入

Categories=GNOME;Application;Development; ：应用程序分类

StartupNotify=true：可选，启动是否弹窗提示，"Type"类型是"Application"时才有意义。



## 2.将文件复制到以下地址：

```shell
sudo cp idea.desktop /usr/share/applications
```

## 3.启动应用程序

打开程序列表，找到添加的xxapp，即可启动。
