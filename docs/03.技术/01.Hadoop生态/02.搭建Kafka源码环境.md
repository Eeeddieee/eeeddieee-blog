# 搭建Kafka源码环境

## 搭建过程
1. 安装1.7以上JDK ，打开命令行使用java -version确认；
2. 下载安装Gradle
    地址：https://gradle.org/releases/  选择跟你下载的Kafka版本发布日期之后的版本，我这里下载的是5.3。下载后解压然后把安装包下的bin目录添加进系统Path中。
    打开命令行，使用gradle -v查看是否正常安装。
    修改gradle版本库为阿里源：
    修改改build.gradle 文件，把https://repo1.maven.org/maven2/替换为http://maven.aliyun.com/nexus/content/groups/public。
如下：
-------------------------------------------
buildscript {
  repositories {
    maven { url 'http://maven.aliyun.com/nexus/content/repositories/central/' }
    mavenCentral()
    jcenter(){ url 'https://jcenter.bintray.com/'}
    maven {
      url "https://plugins.gradle.org/m2/"
    }
  }

allprojects {

--------------------------------------------------------
  repositories {
    maven { url 'http://maven.aliyun.com/nexus/content/repositories/central/' }
    // mavenCentral()
  }


3. 下载并安装Scala
    下载地址：http://www.scala-lang.org/download/all.html 我这里下载的是2.11.8，下载后解压然后把安装包下的bin目录添加进系统Path中。
    打开命令行，使用Scala -version查看是否正常安装。
4. 下载kafka源码并编译
    下载地址：http://kafka.apache.org/downloads  下载需要的版本，根据scala版本选择相应的版本。我下的是2.2.1
    将下载的压缩包解压，并在Kafka的根目录执行gradle idea进行构建。
5. 打开idea，导入项目即可。
