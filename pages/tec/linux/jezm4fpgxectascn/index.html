Ubuntu中vscode不能输入中文原创

# Ubuntu中vscode不能输入中文

# 原因

使用Ubuntu自带的软件中心安装的vscode是阉割版，不支持中文。

# 解决办法

  1. 卸载现有版本
sudo snap remove code
sudo apt remove code
1
2
  1. 官网下载最新dep包
https://code.visualstudio.com/
1
  1. 安装
sudo dpkg -i code_1.80.0-1688479026_amd64.deb
